# ARK Config Creator Wiki

ARK Config Creator turns common ARK: Survival Ascended dedicated-server settings into friendly controls, then generates or deploys the exact server files.

Start with **Server Basics**, choose a preset if useful, adjust the categories you need, and set map/player options under **Launch Options**. Use **Create Files** for manual installation, **Deploy** for supported hosts, or **Set Up Local Server** to create a server on this Windows PC.

See the sidebar for installation, local hosting, deployment, and troubleshooting guides.
