Your Config Files


    

      Where do these files go?

      On your server machine, place both .ini files in:

      …\ARK Survival Ascended Server\ShooterGame\Saved\Config\WindowsServer\

      (For rented servers, most hosts have a config file editor or FTP access — upload/paste them there.)
      Restart the server after changing files. Tip: keep a backup of your old files first!

      Skip the file juggling: the Deploy tab in the sidebar can write these straight to Nitrado,
      a Pterodactyl panel, or a self-hosted server — with automatic backups.
